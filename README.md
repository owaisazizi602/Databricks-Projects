# Databricks-Project

⚙️ Tech Stack

Platform: Databricks

Language: PySpark (Python API for Apache Spark)

Cluster: Databricks Runtime (Spark Environment)

Data Source: attribution.csv (Employee Attrition Dataset)


This project focuses on analyzing and transforming employee attrition data using Apache Spark on Databricks. The dataset (attribution.csv) contains detailed information about employees, including demographics, job satisfaction, income, education, and work-life balance factors.

The objective of the project is to perform data exploration, transformation, and preparation for further machine learning or business insights related to employee attrition trends.
